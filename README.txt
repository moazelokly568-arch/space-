أكاديمية جيو مساحة | GeoMasaha Pro (المرحلة الأولى: نظام الطالب الذكي Student Dashboard)
المنصة الشاملة لهندسة المساحة ونظم المعلومات الجغرافية (GIS)
===================================================================

الجديد في المرحلة الأولى (Student Dashboard):
1. إنشاء حساب جديد للطلاب مع تشفير آمن لكلمات المرور (Web Crypto API SHA-256).
2. تسجيل الدخول وتسجيل الخروج واستمرار الجلسة تلقائياً.
3. استعادة كلمة المرور عبر كود الاستعادة السري (PIN).
4. صفحة شخصية متكاملة ولوحة تحكم ذكية لكل طالب.
5. رفع وتغيير الصورة الشخصية للطالب وتعديل الاسم والتخصص.
6. حفظ الكورسات المفضلة وربطها بحساب الطالب.
7. حفظ آخر درس وصل إليه الطالب مع زر استئناف التعلم السريع.
8. تتبع وعرض نسبة التقدم المئوية (0% إلى 100%) في كل كورس وفي كل درس.
9. حفظ جميع البيانات في قاعدة بيانات حقيقية داخل المتصفح (IndexedDB: GeoMasahaProDB) مع إمكانية تصدير واستيراد قاعدة البيانات (.json) أو ربطها سحابياً بـ Supabase.
10. توافق كامل مع شاشات الموبايل والتابلت والكمبيوتر مع الحفاظ على كافة أقسام وحاسبات ومحتويات الموقع.

طريقة التشغيل على الموبايل والكمبيوتر:
1. قم بفك ضغط الملف (Extract / استخراج).
2. على الموبايل أو الكمبيوتر: افتح ملف (GeoMasaha_Standalone.html) مباشرة بأي متصفح (Chrome, Safari, Edge, Firefox) حيث يحتوي على كل الصور والأكواد مدمجة بداخله، أو افتح (index.html).
