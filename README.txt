أكاديمية جيو مساحة | GeoMasaha Pro (الإصدار الكامل المحدث)
المنصة الشاملة لهندسة المساحة ونظم المعلومات الجغرافية (GIS)
===================================================================

طريقة التشغيل:
1. قم بفك ضغط الملف (Extract All / استخراج الكل).
2. افتح الملف (index.html) أو (GeoMasaha_Standalone.html) بأي متصفح إنترنت (Chrome, Edge, Firefox, Safari).

محتويات الحزمة:
- index.html : نسخة خفيفة وسريعة جداً تقرأ الصورة من مجلد assets/hero.jpg
- GeoMasaha_Standalone.html : نسخة مدمجة بالكامل في ملف واحد (تعمل حتى لو نقلت الملف بمفرده لأي مكان)
- assets/hero.jpg : البنر الهندسي للمنصة
